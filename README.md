# Assignment 1: Student Class Implementation

## 📌 Objective

Create a Java class with attributes and methods to store and display student information.

## 📝 Description

This program demonstrates the basic concepts of **Classes, Objects, Attributes, and Methods** in Java.

The `Student` class contains student details such as:

- Roll Number
- Name
- Course
- Marks

The `displayInfo()` method is used to display the student's information.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)

## 📚 Class Used

### Student

The `Student` class contains the following attributes:

| Attribute | Data Type | Description |
|---|---|---|
| `rollNo` | `int` | Student roll number |
| `name` | `String` | Student name |
| `course` | `String` | Student course |
| `marks` | `int` | Student marks |
